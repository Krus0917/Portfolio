About the project

Building a world
with purpose.

Eden Island Frontier is a 3D strategy simulation game about the implications of climate change. Developed by a six-member team as a capstone project, it brings together gameplay, environment design, and visual assets in one playable experience.

Tools
Unity, Autodesk Maya, Adobe Photoshop, Aseprite
Focus
Game development, 3D assets, environment design, teamwork
